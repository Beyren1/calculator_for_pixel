# Инженерный калькулятор для Android

Калькулятор в стиле Material 3, упакованный в Android-приложение (WebView). Работает без интернета, история и память сохраняются между запусками.

## Как установить

1. Откройте раздел **Releases** этого репозитория на телефоне.
2. Скачайте `calculator.apk` из последней сборки.
3. Откройте файл и разрешите установку из этого источника.

Новые сборки ставятся поверх старой, данные не теряются.

## Как это устроено

- `web/calculator.html` — сам калькулятор (HTML + CSS + JS в одном файле). Меняйте его, остальное подхватится.
- При сборке Gradle оборачивает его в полноценную страницу `app/src/main/assets/index.html`.
- `MainActivity` показывает страницу в WebView и даёт ей вибрацию и буфер обмена.
- GitHub Actions (`.github/workflows/build-apk.yml`) собирает APK при каждом пуше в `main` и публикует его в Releases.

Требования: Android 8.0 и новее.

Приложение подписано ключом `app/debug.keystore`, который лежит в репозитории намеренно, чтобы обновления ставились поверх. Для Google Play нужен отдельный, секретный ключ.
